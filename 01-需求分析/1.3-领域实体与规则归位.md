# 领域实体与业务规则归位

> 本文把散布在 [1.1-产品需求文档.md](1.1-产品需求文档.md)、[1.2.1-复习语言符号.md](1.2-用例/1.2.1-复习语言符号.md)、[1.2.2-词库管理.md](1.2-用例/1.2.2-词库管理.md)、[1.2.3-练习偏好.md](1.2-用例/1.2.3-练习偏好.md) 中的业务规则做**性质分类**，并定义承载产品固有规则的**领域实体**及其不变量。规则正文以各需求文档为准（单源），本文只做归位与定义，不涉及接口与实现。

## 判定方法

业务规则按"与外部系统的耦合程度"分三档：

| 档位 | 含义 | 判定问题 |
| --- | --- | --- |
| **领域固有规则**（实体层） | 产品的固有事实与不变量：换间隔重复引擎、换 AI 服务、换 UI 都不变化 | 换掉 Anki / AI / UI，这条规则还成立吗？ |
| **应用流程规则**（用例层） | 因本系统自动化而存在的练习/复习流程规则，随会话发生 | 没有这套软件就不会存在的交互规则 |
| **外部系统规则** | 由间隔重复引擎（存储、到期调度、统计）或 AI 服务（材料生成、语音）执行；本系统不实现，只经适配层传递约束 | 规则本体在外部系统里 |

## 原则：引擎不决定太多

- 维度集合（读/听/说/写四种）与维度到练习的对应关系、评分档位语义，由**产品定义**；某语言符号实际有哪几张卡属引擎侧数据事实，产品不设定也不假设齐备。
- 间隔重复引擎只负责执行：存储、到期调度、复习统计。
- 任何把产品语义**绑定到具体引擎**的措辞（如"评分对应 Anki Ease"）应理解为适配映射，不是领域定义——换引擎时应调整映射而非调整语义。

## 领域实体

实体 = **关键业务数据 + 关键业务规则**的绑定模块（依据《架构整洁之道》第 20 章），不依赖引擎、AI、UI 的任何类型；只有字段、没有规则承载的数据结构是跨边界数据契约（随外部 schema 变化），不属实体。规则正文以归位表对应编号的来源文档为准，此处只列规则要点。

领域实体共三个：**表达单元、卡片、评分**。需求文档中的"语言符号"、词库管理文档中的"词库条目"与复习中的表达，是同一实体的不同称呼与状态，不是不同实体。

### 表达单元

- **关键业务数据**：意思确定的英语表达 = 词形 + 一个义项（需求文档称**语言符号**；词形可为词、短语或短句，句法长度不是边界；多义时以义项为界——同一词形的不同义项是不同表达单元）。条目取自**词库**——词库是项目自身的语言符号集（由专业词典转换而来），是表达单元的来源目录，分内置词库与使用者补录两层（见 [1.2.2-词库管理.md](1.2-用例/1.2.2-词库管理.md)）。承载它的句子是练习材料，不属实体（见"非实体澄清"）。
- **状态（同一实体的三种状态，可迁移）**：
  - *未学习*——在词库内，既未标记为已掌握、也未标记为复习中；新词引入标出的即它（R19）；
  - *复习中*——作为复习单元，对应读/听/说/写四个维度的卡（实际哪几张由引擎侧数据决定，可不足四张），各卡独立调度（R7）；
  - *已掌握*——处于已掌握词库，作为 AI 生成材料用词的约束数据源（R9），无卡、不调度（R16）。
- **关键业务规则**：R1（基础学习单元）、R7（四维度卡结构、理解内嵌于练习）、R16（词库规则）、R19（新词引入）、R20（用词宇宙）；**状态迁移由使用者显式发起**（未学习 → 复习中 = 使用者要求为该表达建卡入引擎；未学习／复习中 → 已掌握 = 使用者手动标记），系统不自动迁移、不自动为词库建卡、不自动从引擎移除。**状态不随词典替换而变**——已掌握与复习中的状态属于表达单元自身，不依赖具体某部词典。
- 外部关系：复习中状态的文本存档在引擎（Anki note，只存词形与义项，**不含句子**——句子由 AI 按上下文生成，见 R1）；已掌握状态存于本系统；词形与义项由词库条目提供（义项可按需译为中文）。

### 卡片

- **关键业务数据**：所属表达单元、维度（读/听/说/写，四选一）。
- **关键业务规则**：R7 之"维度唯一、该维度决定进入的练习、同单元各卡独立调度（到期互不影响）"。
- 外部关系：卡片的到期状态由引擎计算，经同步镜像供本系统查询。

### 评分

- **关键业务数据**：三档：忘记 / 困难 / 良好。
- **关键业务规则**：R14 之"档位集合固定为三档、档位表达回忆质量"——档位语义由产品定义，不随引擎变化（原则：引擎不决定太多）。
- 外部关系：档位到引擎按钮/数值的对应属适配映射（引擎按钮数不要求与档位数一致），见接口设计。

### 词库条目

词库条目即表达单元本身（词形 + 一个义项）；词库由专业词典转换而来，分内置词库与使用者补录两层——补录条目与内置条目地位相同。表达单元的"已掌握"状态即**已掌握词库条目**（数据与规则见上节）。两者的管理操作见 [1.2.2-词库管理.md](1.2-用例/1.2.2-词库管理.md)。

## 非实体澄清

以下对象**不是**领域实体，不要为它们做"实体化"设计：

- **引擎条目的镜像数据**（如 Anki 卡片/笔记的镜像条目）：外部数据契约，跨边界传递用。
- **练习会话、练习材料、AI 建议评分**：因自动化而生的用例层对象。
- 需求文档字段列表中的词汇（例句、练习内的释义等）：辅助材料，无固有规则。
- **词库与词典**：都不是独立实体——词库是表达单元的来源目录，条目即表达单元（词形 + 义项），分内置词库与使用者补录两层；词典是词库的外部来源（专业词典，词库由它转换而来），换词典属数据替换、重建词库，不改动产品规则（状态不随词典替换而变，见表达单元）。
