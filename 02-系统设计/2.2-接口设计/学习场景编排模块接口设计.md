# 学习场景编排模块接口设计

## 在架构中的位置

```
AppCoordinator ──> ISceneOrchestrator ──> IAIManager
```

- `AppCoordinator` 通过 `ISceneOrchestrator` 为指定词汇生成学习场景，不直接接触 AI 接口。
- `ISceneOrchestrator` 内部调用 `IAIManager`，将 AI 回复组装为结构化场景。

## 核心概念

### SceneType — 四种技能场景

| 类型 | 学习步骤 | 说明 |
|------|----------|------|
| `READING` | 文字 → 意思 | 看英语句子，不思考中文，直接想象句子描述的场景 |
| `WRITING` | 想法 → 打字 | 给定场景/想法，用户打出对应的英语句子 |
| `LISTENING` | 声音 → 意思 | 听英语句子，在脑海中想象场景 |
| `SPEAKING` | 想法 → 发声 | 给定场景，用户说出对应的英语句子 |

### LearningScene — 场景内容结构

每种 `sceneType` 的 `content`（JSON）结构如下：

**READING**
```json
[
  {
    "sentence": "The cat is sleeping on the sofa.",
    "translation": "猫在沙发上睡觉",
    "sceneDescription": "一只猫蜷缩在沙发上，闭着眼睛睡觉"
  }
]
```

**WRITING**
```json
[
  {
    "scenario": "你想告诉朋友猫在沙发上睡觉",
    "keywords": ["cat", "sleeping", "sofa"],
    "referenceSentence": "The cat is sleeping on the sofa."
  }
]
```

**LISTENING**
```json
[
  {
    "audioText": "The cat is sleeping on the sofa.",
    "translation": "猫在沙发上睡觉",
    "sceneHint": "想象一只猫在沙发上的画面"
  }
]
```

**SPEAKING**
```json
[
  {
    "scenario": "你看到猫在沙发上睡觉，想说出来",
    "targetSentence": "The cat is sleeping on the sofa.",
    "pronunciationGuide": "注意 sleeping 的 /iː/ 发音"
  }
]
```

### 接口方法

| 方法 | 说明 |
|------|------|
| `generateScene` | 异步生成场景，返回 `sceneId`，结果通过信号返回 |
| `cancelGeneration` | 取消正在生成的场景 |
| `getScene` | 根据 `sceneId` 获取已生成的场景内容 |

### 信号（Qt Signal）

| 信号 | 触发时机 |
|------|----------|
| `sceneReady(sceneId, scene)` | 场景生成完成，携带完整的 `LearningScene` |
| `sceneError(sceneId, error)` | 场景生成过程中出错 |

> **注意**：`generateScene` 不阻塞调用方。调用后立即返回 `sceneId`，场景生成完成后通过 `sceneReady` 信号推送结果。调用方监听该信号即可获取场景。

## 典型流程

```
AppCoordinator       ISceneOrchestrator      IAIManager
     │                      │                    │
     ├─generateScene(       │                    │
     │  entries, READING,    │                    │
     │  config)────────────┤                    │
     │◄──返回 sceneId ──────┤                    │
     │                      │── sendMessage()───>│
     │                      │<── replyFinished ──┤
     │                      │  (组装 LearningScene)
     │◄──sceneReady( scene )┤                    │
     │  (UI 渲染场景)       │                    │
```

## 与周边模块的关系

| 对端模块 | 数据流向 | 内容 |
|----------|----------|------|
| AppCoordinator → ISceneOrchestrator | 入参 | `List<MemEntry>` + `SceneType` + `SceneConfig` |
| ISceneOrchestrator → AppCoordinator | 信号 | `LearningScene` |
| ISceneOrchestrator → IAIManager | 内部调用 | 封装为 system prompt + user message |
