# 学习场景编排模块接口设计

## 在架构中的位置

```
AppCoordinator ──> ISceneOrchestrator ──> IAIManager
```

- `AppCoordinator` 通过 `ISceneOrchestrator` 创建学习对话、收发消息，不直接接触 AI 接口。
- `ISceneOrchestrator` 内部调用 `IAIManager`，管理学习对话的完整生命周期。

## 核心概念

### 设计思路：从"生成内容"到"创建对话"

旧设计将 AI 视为一次性内容生成器 —— 给词汇、选类型，AI 返回一组静态的练习题，用户被动浏览。

新设计的核心变化：**学习场景 = 一次 AI 对话**。SceneOrchestrator 的角色是：

1. 根据场景类型（听说读写）为 AI 设定**角色与行为规则**（system prompt）
2. 创建一个**学习对话会话**（SceneSession）
3. 用户在该会话中与 AI **多轮交互**，在对话中练习英语
4. AI 根据用户的每次回复给出**即时反馈、纠正、引导**

这样听说读写不再是做完就走的"题目"，而是和 AI 持续互动的学习过程。

### SceneType — 四种技能场景（AI 角色）

| 类型 | AI 角色 | 典型对话模式 |
|------|---------|-------------|
| `READING` | **阅读引导者**：展示围绕目标词汇的英语句子，引导用户不借助中文直接想象场景。通过提问检查理解程度。 | AI 发句子 → 用户描述理解的场景 → AI 纠正/确认 → 下一句 |
| `WRITING` | **写作教练**：给出中文场景描述，让用户写出对应的英语句子。AI 检查语法、用词，给出参考句子和解释。 | AI 描述场景 → 用户打英语句子 → AI 批改 + 参考句 |
| `LISTENING` | **听力陪练**：提供音频文本（后续版本接入 TTS），用户听后理解内容。AI 验证理解，逐步提高难度。 | AI 提供句子/播放音频 → 用户复述或描述 → AI 纠正 |
| `SPEAKING` | **口语教练**：给出场景，让用户说出英语句子。AI 检查发音要点，给出反馈和改进建议。 | AI 描述场景 → 用户说出句子 → AI 纠正发音/表达 |

### SceneSession — 学习对话会话

一次学习对话就是一个 `SceneSession`，它不是预先生成的静态内容，而是用户与 AI 多轮交互的载体。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 会话唯一标识 |
| `type` | SceneType | 场景类型，决定 AI 的行为角色 |
| `entries` | List\<MemEntry\> | 本场景覆盖的词汇条目 |
| `systemPrompt` | String | 系统提示词，createSession 时根据 type + entries 生成 |
| `roundCount` | Int | 当前已完成的对话轮数 |
| `status` | SessionStatus | 会话状态：CREATING → ACTIVE → ENDED |
| `createdAt` | Int64 | 创建时间戳 |

### 接口方法

| 方法 | 说明 |
|------|------|
| `createSession(entries, sceneType, config)` | 创建学习对话会话。根据 sceneType 和 entries 构建 system prompt，设定 AI 角色。异步，结果通过 `sessionCreated` 信号返回。 |
| `sendMessage(sessionId, content)` | 在指定会话中发送用户消息。AI 回复通过 `responseStreaming` / `responseComplete` 信号异步返回。 |
| `stopResponse(sessionId)` | 停止当前 AI 响应生成（用户中途打断）。 |
| `endSession(sessionId)` | 结束学习对话，释放相关资源。触发 `sessionEnded` 信号。 |
| `getSession(sessionId)` | 获取会话信息，用于恢复会话或查询状态。 |

### 信号（Qt Signal）

| 信号 | 触发时机 |
|------|----------|
| `sessionCreated(sessionId)` | 学习对话创建完成，AI 已就绪，UI 可展示对话界面 |
| `responseStreaming(sessionId, chunk)` | AI 回复的流式片段，UI 逐字展示 |
| `responseComplete(sessionId, message)` | AI 回复完成，携带完整消息内容 |
| `sessionError(sessionId, error)` | 会话过程中出错（创建失败、AI 调用失败等） |
| `sessionEnded(sessionId)` | 对话结束，UI 可展示总结或退出 |

## 典型流程

### 创建并开始学习对话

```
AppCoordinator       ISceneOrchestrator      IAIManager
     │                      │                    │
     ├─createSession(       │                    │
     │  entries, READING,    │                    │
     │  config)─────────────┤                    │
     │◄──返回 sessionId ────┤                    │
     │                      │── sendMessage() ──>│
     │                      │   (system prompt   │
     │                      │    初始化 AI 角色)  │
     │                      │<── replyFinished ──┤
     │                      │   (AI 开场白)      │
     │◄──sessionCreated─────┤                    │
     │  (UI 展示对话界面)    │                    │
```

### 多轮交互

```
AppCoordinator       ISceneOrchestrator      IAIManager
     │                      │                    │
     │  (用户输入消息)       │                    │
     ├─sendMessage(         │                    │
     │  sessionId,           │                    │
     │  userMessage)────────┤                    │
     │                      │── sendMessage() ──>│
     │                      │   (携带对话历史)    │
     │◄──responseStreaming──┤<── streamChunk ────┤
     │◄──responseStreaming──┤<── streamChunk ────┤
     │◄──responseComplete───┤<── replyFinished ──┤
     │                      │                    │
     │  (用户继续回复...)    │                    │
     │  ...多轮交互...      │                    │
     │                      │                    │
     ├─endSession(id)───────┤                    │
     │◄──sessionEnded───────┤                    │
```

## 与周边模块的关系

| 对端模块 | 数据流向 | 内容 |
|----------|----------|------|
| AppCoordinator → ISceneOrchestrator | 入参 | `List<MemEntry>` + `SceneType` + `SceneConfig` |
| ISceneOrchestrator → AppCoordinator | 信号 | `sessionCreated` / `responseStreaming` / `responseComplete` / `sessionEnded` |
| ISceneOrchestrator → IAIManager | 内部调用 | 构建 system prompt + 维护对话历史 + 发送用户消息 |

## System Prompt 构建

`createSession` 的核心工作之一是根据 `SceneType` 和 `entries` 构建 system prompt。各类型 prompt 要点：

| SceneType | Prompt 要点 |
|-----------|------------|
| READING | 使用以下词汇生成简单英语句子；每次展示一句；引导用户不翻译、直接想象场景；用英语提问检查理解 |
| WRITING | 每次给出一个中文场景描述；等待用户写出英语句子；检查语法和用词，给出参考句；用中文解释关键错误 |
| LISTENING | 每次给出一个英语句子；让用户听后描述理解的内容；逐步提高句子难度和语速说明 |
| SPEAKING | 每次给出一个场景；让用户说出英语句子；指出发音要点和常见错误；鼓励多开口 |

> prompt 模板和注入的记忆数据格式参见 [提示词模板](../../03-详细设计/提示词模板.md)。
