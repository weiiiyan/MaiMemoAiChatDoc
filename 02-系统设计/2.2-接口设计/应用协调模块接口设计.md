# 应用协调模块接口设计

## 职责定位

应用协调模块（`IAppCoordinator`）是整个应用的**入口与中枢**，核心职责：

- **定义交互接口**：作为 UI 与后端模块之间的桥梁，定义 UI 可调用的操作入口。
- **协调工作流程**：串联 DataSync、SceneOrchestrator、Persistence 等模块完成完整的业务流程（复习、对话等）。
- **生命周期管理**：负责所有子模块的初始化与销毁。

### 在架构中的位置

```
UI ──> IAppCoordinator ──> ISceneOrchestrator
                    │──> IDataSync
                    └──> Hold (Persistence)
```

- **UI** 通过 `IAppCoordinator` 触发应用操作（初始化、复习等），不直接接触后端模块。
- **AppCoordinator** 内部持有所有子模块引用，编排完整流程，并通过 `IUIModule` 更新 UI。

## 接口方法

| 方法 | 调用方 | 说明 |
|------|--------|------|
| `initialize(ui, config)` → Bool | main.cpp | 启动应用：加载配置 → 初始化子模块 → 连接信号 → 恢复会话 |
| `shutdown()` | main.cpp | 安全关闭：保存状态 → 断开引擎 → 释放资源 |
| `isInitialized()` → Bool | UI / main.cpp | 检查初始化状态 |
| `startReview()` | UI | 触发复习流程：`getDueEntries → generateScenes → showCardReviewView` |
| `dueEntryCount()` → Int | UI | 获取到期条目数，供角标/提示展示 |

## 与 UI 模块的协作

AppCoordinator 与 UI 模块采用**双向接口引用**的模式协作：

```
┌─────────────────────────────────────────────────┐
│                    main.cpp                       │
│                                                    │
│  appCoord.initialize(uiModule, config)             │
│       │                                            │
│       ├─ IAppCoordinator 内部:                      │
│       │   ├─ 初始化所有子模块                        │
│       │   ├─ 连接 IUIModule 信号 → 内部 slot        │
│       │   │   ├─ messageSent → handleMessage        │
│       │   │   ├─ reviewAnswered → handleReview       │
│       │   │   └─ settingsChanged → handleSetting     │
│       │   └─ 调用 IUIModule 方法恢复 UI 状态        │
│       │       └─ showChatView(lastSessionId)         │
│       └──── return                                   │
└─────────────────────────────────────────────────┘
```

关键点：
- **AppCoordinator 不发射信号** — 它直接调用 `IUIModule` 方法来驱动 UI 变更。
- **UI 不直接调用 IAppCoordinator 业务方法** — 它通过 `IUIModule` 信号触发，AppCoordinator 监听后编排。
- `initialize(ui, config)` 是唯一的显式调用入口，传入 `IUIModule` 引用完成全部信号连接。

## 典型流程

### 应用启动

```
main.cpp            IAppCoordinator          IUIModule          DataSync/Scene
   │                      │                     │                    │
   ├─initialize(ui,cfg)───┤                     │                    │
   │                      ├─ 初始化子模块 ──────┤                    │
   │                      ├─ 连接信号 ──────────┤                    │
   │                      ├─ 恢复上次会话 ──────┤                    │
   │                      │   showChatView() ──>│                    │
   │◄──── return true ────┤                     │                    │
```

### 复习流程

```
UI 点击"开始复习"     IAppCoordinator     IDataSync      ISceneOrchestrator
   │                      │                  │                  │
   │ IUIModule 信号       │                  │                  │
   │ ──reviewRequested───>│                  │                  │
   │                      ├─getDueEntries()─>│                  │
   │                      │◄──List<MemEntry>─┤                  │
   │                      ├─generateScene(   │                  │
   │                      │   entries, READING,    │                  │
   │                      │   config)──────────┤─────sceneId────>│
   │                      │                  │                  │
   │                      │◄──sceneReady─────┤──────────────────┤
   │                      ├─showCardReview()─>│                  │
   │◄── UI 展示复习 ──────┤                   │                  │
```
