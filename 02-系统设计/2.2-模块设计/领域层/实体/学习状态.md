# 学习状态 `LearningState`

> 所属：[领域层](../领域层.md)。

## 数据

| 类型 | 取值 |
| --- | --- |
| 维度 `Dimension` | 读 / 听 / 说 / 写；**决定进入哪种练习**，理解内嵌于练习（R3） |
| 状态 | 未学习 / 复习中 / 已掌握，**三态互斥**（同一时刻只一种，R4） |

**身份＝（表达单元, 维度）**：同一词形的不同义项各算各的，同一义项的各维度各算各的（即 R8 判重的键）。

一条学习状态＝（表达单元, 维度, 状态值）；**未学习是缺省**——没有标记即未学习，不需要记录。状态收在[学习状态集](../集合/学习状态集.md)里。

三态的语义：

- *未学习*——在词库内，既未标记已掌握、也未标记复习中；新词引入标出的即它。
- *复习中*——该（表达单元, 维度）在引擎里由**一张卡**替它执行调度（实际有哪几张由引擎侧数据决定，可不足四张）。
- *已掌握*——作 AI 生成材料的用词约束数据源（R12），该维度无卡、不受调度；它是**使用者的主观声明**，不与引擎的"掌握评估"混同（归位表·学习状态）。

## 迁移规则

| 规则 | 语义 | 依据 |
| --- | --- | --- |
| 六种迁移两两可行 | 任意两个不同状态间的迁移都合法，无单向限制 | R4 |
| 全部由使用者显式发起 | 不自动迁移，也不依据复习数据自动增减状态 | R4 |
| 只改状态 | 不改动条目本身，也不动其他维度的状态与卡（各维度独立） | R5 |
| 状态属于表达单元自身 | 不随词典替换而变 | R5 |
| 撤卡即删除、不可逆 | 属应用流程，本层不做：由「同步间隔重复引擎状态」用例执行引擎侧动作 | R6 |
| 有损需确认 | 迁出非未学习即是有损（取消已掌握标记，或使该维度的卡待删），要确认——**属应用流程**：由用例判定并要求确认，本层不做 | R25 |

> 换词典时的状态接续：状态的身份是（[表达单元](表达单元.md) × 维度），而表达单元的身份是（词形, 义项）——所以重建词库后按**字面键**自动对接；义项被新词典改写的条目会落空。取舍属词典转换（另一刀）。

## 接口

取值本身，**无行为**（与[评分](评分.md)同）：三态是值，迁移是值被替换；上表的规则是**约束**，由[学习状态集](../集合/学习状态集.md) 的 `setState` 守住，本实体不需要提供操作。
