# 词库（表达单元的集合）

> 所属：[领域层](../领域层.md)。**是容器、不是实体**：词库没有独立于条目的数据（归位表·非实体澄清），条目即[表达单元](../实体/表达单元.md)；它承载的是**集合级规则**——判重。

## 数据

- **成员**：表达单元。
- **键**：表达单元的[身份](../实体/表达单元.md)——同一词形、同一义项在词库中只记一条（R8）。
- **不记来源**：词典转换来的与使用者补录的**不区分**——需求里"两层条目地位相同"落成"根本不区分"；换词典时的取舍留到那时再定（若需要，来源再加回来）。

## 接口

| 成员 | 语义 |
| --- | --- |
| `insert(条目)` | 入库；两种结果——`Added` / `Duplicate`（身份已存在，不入） |
| `contains(条目)` | 按身份问"有没有"（补录与批量导入的入库判定） |
| `find(条目)` | 按身份取条目；取回的是**库里存的那一份**（原样词形是第一次入库时的） |
| `all()` | 全量条目，按身份排序 |

> 入参是**表达单元**——必填检查在 `ExpressionUnit::create` 里做过，本集合只判重；词库条目将来长字段，这几个方法一个字不用改。
> 浏览/搜索的过滤是用例的取用方式，属应用层，不在本集合。
