# 学习状态集（学习状态的集合）

> 所属：[领域层](../领域层.md)。容器：把每个[学习状态](../实体/学习状态.md)按身份收在一起，承载"同一（表达单元, 维度）只记一条"的集合级规则。

## 数据

- **键**：（[表达单元](../实体/表达单元.md), 维度）。
- **未学习是缺省**：没有记录即未学习；集合只存**已掌握**与**复习中**（三态里的未学习就是"没有标记"）。

## 接口

| 成员 | 语义 |
| --- | --- |
| `stateOf(条目, 维度)` | 取状态；无记录返回**未学习** |
| `setState(条目, 维度, 状态)` | 落状态；置为**未学习**即删掉记录 |
| `masteredIn(维度)` | 该维度上全部已掌握的表达单元——**已掌握词库**（R12 用词上限的数据源） |
