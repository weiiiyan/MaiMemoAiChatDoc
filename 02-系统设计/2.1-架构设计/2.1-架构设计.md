## 模块功能确定

| 模块       | 功能                                          |
| -------- | ------------------------------------------- |
| UI模块     | 交互（信息显示与接收）                                 |
| 应用协调模块   | 定义交互接口；协调其他模块的工作流程；                         |
| 持久化模块    | 保存其他模块需要持久化的数据；保证持久化数据不分散（方便同步）；实现通用的持久化机制； |
| 学习场景编排模块 | 抽象调用一个或多个ai的接口；对内保持接口稳定；                    |
| 数据同步模块   | 抽象使用一个或多个间隔重复算法与记忆数据库；对内保持接口稳定；             |

### 持久化模块

持久化模块的核心功能有两个：

- 集中整个app的上下文存储 -- 方便管理（回退，多端同步等）。
- 实现通用的持久化机制 -- 多线程，甚至多进程异步存储（不用等文件io）、使用临时文件等机制防止磁盘满等异常、使用延时（比如有写入时，等5秒，如果这5秒更新了写入，只用写入最新那次）或其他办法减少写入次数等。

### 数据同步模块

数据同步模块（`IDataSync`）位于**应用协调模块**与**间隔重复引擎**之间，核心职责：

- **抽象 SRS 引擎差异**：统一墨墨背单词、Anki 等不同引擎的访问方式，对内提供一致接口。
- **记忆数据管理**：提供词汇条目的查询、更新能力，作为学习场景编排的数据源。
- **双向同步**：协调本地状态（学习结果）与远程或本地引擎之间的数据一致性。

### 学习场景编排模块

学习场景编排模块（`ISceneOrchestrator`）位于**应用协调模块**与**AI 服务**之间，核心职责：

- **抽象 AI 调用**：封装与 AI API 的交互细节，对内保持接口稳定。
- **创建学习对话**：根据词汇记忆数据（`MemEntry`）和场景类型，为 AI 设置角色提示词，创建交互式学习对话。
- **管理多轮交互**：在学习对话中收发消息，支持流式响应，管理对话的完整生命周期。

注：学习场景就是一次ai学习对话。
